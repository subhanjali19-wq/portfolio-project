# Portfolio Project

## Objective

This repository documents both the environment setup and the research completed as part of the portfolio project.

The research focuses on AI-Powered SEO, Generative Engine Optimization (GEO), and AI content production by studying leading industry experts and organizing their insights into a structured knowledge base.

---

The repository contains research on the following experts:

- Kevin Indig
- Mike King
- Cyrus Shepard
- Ross Simmonds
- Gaetano DiNardi

**Total Experts Researched:** 10

For each expert, the repository includes:

- Professional background
- Analysis of recent LinkedIn posts
- Key takeaways from YouTube interviews or podcasts
- One additional resource (newsletter, blog, or research article)

A consolidated `sources.md` file provides links, dates, and brief annotations for all experts.

## Challenges Encountered

### Issue 1: Claude Code extension was not visible

Initially, I could not find the Claude Code extension in Cursor.

**Solution:**

I opened the Extensions Marketplace and searched again. The extension appeared and was installed successfully.

---

### Issue 2: Codex extension setup

After installing Codex, I needed to sign in with my OpenAI account.

**Solution:**

I completed the authentication process and verified that Codex was working correctly.

---

### Issue 3: Git was not installed

When I tried to clone the repository in Cursor, Git commands were not available.

**Solution:**

I installed Git for Windows, verified the installation using `git --version`, cloned the repository successfully, and confirmed it was synchronized with GitHub using `git status`.

---

### Issue 4: Organizing research into a consistent structure

As the number of research files increased, maintaining a consistent folder structure, naming convention, and documentation became important.

**Solution:**

I organized the repository into dedicated folders for LinkedIn posts, YouTube transcripts, and additional resources. I also maintained a consolidated `sources.md` file to keep all expert references organized and easy to navigate.
